# /ab-100

Execute the AB-100 evaluation comparing baseline (flags off) vs enhanced (flags on).

## Input
- Read `tests/ab_100.jsonl` (100 test samples)
- Read `tests/acceptance_check.py`
- Read `.claude/docs/scoring.md` for metrics definitions

## Process
1. Load 100 samples from `tests/ab_100.jsonl`
2. **Run A (baseline)**: All feature flags OFF
   - For each sample: translate, score, log
   - Write `production/quality_logs/ab_100_A.jsonl`
3. **Run B (enhanced)**: All feature flags ON
   - For each sample: translate, score, log
   - Write `production/quality_logs/ab_100_B.jsonl`
4. Compute metrics:
   - success_rate_A / success_rate_B
   - format_break_rate_A / format_break_rate_B
   - term_consistency_A / term_consistency_B
   - reviewer_trigger_rate_B
   - reviewer_improvement_rate_B
5. Compare and conclude: Keep or Rollback

## Pass Criteria
- B format_break_rate ≤ A format_break_rate (no regression on structure)
- B term_consistency ≥ A term_consistency (improvement on terminology)
- reviewer_improvement_rate_B > 0 (reviewer provides value)
- Report includes clear Keep/Rollback conclusion

## Output Contract
- Write `production/reports/ab_100_report.md`
- Write `production/quality_logs/ab_100_A.jsonl`
- Write `production/quality_logs/ab_100_B.jsonl`
